# Route catalog

The offline route catalog contains community coordinate and QT metadata from
[starmap.space](https://starmap.space/) and the
[Star Citizen Wiki API](https://api.star-citizen.wiki/), retrieved 2026-10-21.
Per-marker source URLs and coordinate approximation methods are retained in
`route-data/quantum-markers.json`. These sources are not affiliated with this
project. The project's code license does not override third-party data rights.


## Map references

Approximate star coordinates use starmap.space; source URLs remain in
`route-data/stars.json`. Aaron Halo band boundaries derive from CaptSheppard's
[Cornerstone survey](https://cstone.space/resources/knowledge-base/65-aaron-halo-detailed-shape-and-density-survey), measured in 3.16.1.
The survey source and version remain in `route-data/aaron-halo.json`.
Map textures and symbols are generated by this application; no game art is included.

## Refinery reference data

Refinery ore bonuses and relative method ratings are provided by UEX
(https://uexcorp.space/), snapshot retrieved 2026-10-24 from its public
`refineries_yields` and `refineries_methods` API endpoints. Per-record report
timestamps remain in `route-data/refineries-uex.json`. Data is community-maintained,
may differ from live servers, and is not endorsed by CIG or RSI. The code license
does not override third-party data rights. UEX is independent of this project.
