# Third-party components

The project license applies to SC Bookmarks code, not to separately installed dependencies or third-party trademarks. Dependencies and their bundled components retain their own licenses and notices. No Python interpreter, OCR model, game artwork, or dependency binary is redistributed in this source archive.

Direct dependencies are installed from PyPI by Setup:

- [Pillow](https://pypi.org/project/Pillow/)
- [NumPy](https://pypi.org/project/numpy/)
- [OpenCV Python](https://pypi.org/project/opencv-python/)
- [ONNX Runtime](https://pypi.org/project/onnxruntime/)
- [RapidOCR ONNX Runtime](https://pypi.org/project/rapidocr-onnxruntime/), including its separately packaged OCR assets
- [Windows Capture](https://pypi.org/project/windows-capture/)

Consult each installed distribution's license files for full terms, including bundled components and transitive dependencies. Python and Tcl/Tk are separately installed runtimes with their own licenses.

Ore names were checked against the [SCMiner mineral directory](https://scminer.rocks/data/mineral-directory); only names are included. The bundled scan tables are reference data, not official game documentation or a guarantee of current in-game results.
